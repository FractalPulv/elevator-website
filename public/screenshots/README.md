# App screenshots

Drop real iPhone screenshots here as PNGs, then pass the path to `<PhoneMockup src="/screenshots/your-file.png" />`.

Recommended: tall portrait shots at the iPhone 15/16 aspect ratio (1179 × 2556) so they fill the frame without distortion. Suggested names:

- `scoreboard-dark.png`
- `scoreboard-light.png`
- `spectator.png`

Until these exist, `PhoneMockup` renders the styled `ScoreScreen` placeholder.
